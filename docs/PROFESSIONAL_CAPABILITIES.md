# Professional Capabilities & Evidence

This is a plain-language map of the work I can discuss with a hiring manager. It connects experience from retail, customer-facing operations, an owner-operated instrument repair business and independent systems projects.

**Evidence language:** *Public source* means code or documentation is inspectable here, not that a system was deployed. *Original record reviewed privately* means underlying business material was checked without publishing it. *Firsthand account* means I can explain the activity, but it has not been independently employer-certified. A business outcome is stated only where the available evidence supports it.
